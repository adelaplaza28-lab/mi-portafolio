Refugio Patitas Felices

Sistema backend integral de gestión de adopciones, manejo de inventario y autenticación segura para organizaciones de rescate animal.

1. El Desafío y Contexto

El refugio requería una plataforma capaz de centralizar la administración de rescates, procesos de adopción y almacenamiento masivo de imágenes de los animales. El principal reto residía en garantizar la seguridad en los roles administrativos, la persistencia eficiente de datos y la carga controlada de archivos multimedia mediante servicios robustos.

Stack Tecnológico & Arquitectura

Se diseñó una arquitectura RESTful escalable utilizando Node.js y Express, integrada a una base de datos PostgreSQL mediante el ORM Sequelize para mantener la integridad referencial.

Seguridad y Manejo de Multimedia

Implementación de tokens JWT con contraseñas encriptadas mediante bcrypt para el control de sesiones administrativas, junto a la configuración del middleware Multer para el procesamiento y filtrado de fotografías subidas al servidor.

3. Impacto y Métricas de Desempeño

El desarrollo logró automatizar y optimizar la gestión operativa del refugio, obteniendo resultados clave en eficiencia y seguridad:

  • Autenticación: 100% de los endpoints administrativos protegidos contra accesos no autorizados.
  • Estructura BD: Modelado de entidades normalizadas garantizando 0% de redundancia de datos.
  • Optimización API: Tiempos de respuesta menores a 120ms en consultas a la base de datos PostgreSQL.
  • Gestión Multimedia: Carga de archivos validada por tipo de extensión y límite de tamaño.
