DESCRIPCIÓN DEL PROYECTO
Sitio web interactivo de portafolio profesional y presentación de proyectos técnicos, diseñado para exhibir arquitecturas backend, APIs RESTful y casos de estudio destacados.

ESTRUCTURA DEL SITIO
- index.html: Página principal con presentación, resumen profesional y mosaico de proyectos.
- landing.html: Caso de Estudio destacado (Sistema de gestión para refugio de animales "Patitas Felices" con Node.js, Express, PostgreSQL, JWT y Multer).
- assets/: Estilos CSS, scripts de interacción JS y fuentes.
- images/: Fotografías e capturas de interfaz de los proyectos.

TECNOLOGÍAS UTILIZADAS EN LOS PROYECTOS
- Node.js & Express.js
- PostgreSQL & Sequelize ORM
- Autenticación con JWT & Bcrypt
- Carga de archivos multimedia con Multer
- HTML5, CSS3, JavaScript (Frontend Base)
